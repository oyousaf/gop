# 🌿 Gardens of Paradise

A content-driven web platform exploring faith, reflection, and knowledge — built with a strong focus on performance, motion, and scalable content delivery.

Designed to support rich media, structured content ingestion, and a calm, intentional browsing experience.

---

## ✨ Highlights

- ▲ **Next.js 16** (App Router) with Turbopack for fast iteration
- 🎬 **Framer Motion** for subtle, purpose-driven animations
- 📰 **Content aggregation & parsing** using RSS, Cheerio, and Puppeteer
- 🎥 **Media support** including HLS video streaming
- 🌙 **Hijri date handling** via moment-hijri
- 📈 **Analytics integrated** (GA4 + Vercel Analytics)
- 📱 **Responsive, scroll-driven navigation**
- 🔍 **SEO-aware architecture** with next-sitemap
